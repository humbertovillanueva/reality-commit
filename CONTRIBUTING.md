# Contributing

Use Node.js 22.12 or newer. Run `npm ci`, then `npm run dev`.

Create a branch for your change, add tests for domain behavior, and run `npm test` and `npm run build` before opening a pull request. Include a short explanation and screenshots for interface changes. Never commit private site imagery or access tokens.

Good first contributions:

- Validated JSON import with an explicit overwrite confirmation.
- Keyboard-accessible image annotation and dialog focus management.
- Capture coverage notes to distinguish incomplete views from missing assets.
- Tests for local storage failures and upload validation.

Keep proposals separate from verified decisions. Preserve uncertainty instead of inventing confidence. Discuss new external services before introducing uploads or API keys.

Repository collaborators need an invitation from the owner. Public visibility allows cloning and forks; it does not grant direct push access.
